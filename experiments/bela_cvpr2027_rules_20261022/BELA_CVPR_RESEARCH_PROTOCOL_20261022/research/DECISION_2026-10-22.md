# BELA / ELVA | 2026-10-22 独立研究决策

## 当前判断与禁忌
**优先做 W2048 同预算 Token 生命周期分配消融；不直接给现役模型添加新模块。**
这是“有待验证的高价值假说”，不是“深层压到 16 必然提点”。

主假说 H1：BELA 在 decoder 后 20 层始终留 32 个视觉 Token，可能挤占了前中层更有用的预算。在固定 W2048、Stage1、剪枝层位和选择器条件下，减少深层 K 并增加中段 K，有望改善 GQA/POPE。
反假说 H0：BELA 的主要失败来自 Stage1 对查询相关对象证据的漏选、早期剪枝位置、评测口径或交互排序；深层 K 从 32 改成 20/16/12 不会改善准确率，甚至因可用证据减少而变差。

H2：在较深 decoder 层，昂贵的 RDRIFT 选点可能不如廉价随机/stride 选点；但这在 BELA 与 OCR/GQA/POPE 上尚未得到实测支持。比较须固定 K、层位、入口 ID 和随机种子，报告随机均值与方差。

H3：复杂度动态入口可能有效，但 E014/AEE 的历史结果并非单调正收益。优先验证 COVER 残余覆盖需求/有效秩等能否预测“额外入口 Token 的真实边际收益”；必须超过同分配直方图乱序分配，而非只超过弱固定基线。

## 预算与口径
LLaVA 1.5 7B 原始视图基准 576×32=18432 visual token-layers。
W2048 的代理剪枝比率为 1−2048/18432 ≈ 88.89%；W1024 为 ≈94.44%。
二者不是模型 FLOPs/真实延迟降幅，也不等同于论文中“最终 K64/K32”。

历史 BELA W2048（报告值）：GQA57.84 / POPE F1 83.31 / MME1767.83 / MMBench62.20，R4=95.7575%（按历史给定的 61.9、85.8、1852、64.1 参考值）。
历史 W1024（历史 PCOV + Q-Attn 固定选择配置）：GQA55.41 / POPE78.77，其他指标须从原始日志提取，不能随意填充。
**协议红旗**：项目“Dense 参考” MME=1852，STAR-Pro/QCPruner 的 LLaVA-1.5-7B Dense MME=1506.5。评分版本/任务范围核对前禁止声称 MME 绝对值超过外部方法。
文献和历史结果没有本轮 GPU 复现。旧 E014 不是当前生产工程。

## Gate T1 — 第一次：只变中后层配比（最关键）
固定双层 COVER、RDRIFT、Stage1=172、第一次/第二次剪枝边界 4/12、W2048。
- A0 172×4 + 90×8 +32×20 =2048（历史锚点）
- A1 172×4 +110×8 +24×20 =2048
- A2 172×4 +120×8 +20×20 =2048
- A3 172×4 +130×8 +16×20 =2048
- A4 172×4 +140×8 +12×20 =2048
这组仅改变中后层分配，直接检验“深层 32 是否浪费预算”。可先运行 A0/A2/A3，补充 A1/A4 视结果而定。不得在决定结果后私自补改指标口径。

## Gate T2 — 第二次：更少入口、更长前期交互（不同假说）
- B0 128×12 +37×8 +18×12 =2048（STAR-Pro 预算形状，但用 BELA 自己的 COVER/RDRIFT；不等于复现 STAR-Pro 算法）
- B1 128×12 +40×8 +16×12 =2048
- B2 128×12 +46×8 +12×12 =2048
另有 C 组把入口选择器替换为倒数第二层或随机/stride，用于量化不同 Stage1 下的日程敏感性；务必报告选择器-日程二因素相互作用，防止将改入口与改层位造成的增益混为一谈。

## Gate T3 — 高压缩 W1024（不能被 W2048 遮住）
- C0 60×10+28×10+12×12=1024（历史 PCOV+Q-Attn 锚点）
- C1 60×10+34×10+7×12=1024
- C2 60×10+22×10+17×12=1024
- C3 64×12+17×8+10×12=1024（STAR-Pro 预算形状，用 BELA 选择器）
W1024 当前末段已经只有 12 个，所以“深层 32 太多”不解释该工作点全部的 POPE 退化。

## Gate T4 — 选择器和跨模块逻辑
在最有希望的两个日程上固定候选集，比较：
1) RDRIFT / Q-Attn / fixed-stride / seeded random（最后一次剪枝，至少三个随机种子）；
2) COVER vs 同 K 的 penultimate baseline；报告 Stage1×Stage2 的独立增益和交互项；
3) 保持 Patch ID 不变，仅推迟其删除层位的受控实验（标注额外 W），区分 Token 身份与生命周期；
4) POPE FP/FN/子集、GQA 类别/逐题 Dense→BELA 错误，至少在主确认集上报告；
5) 各路径真实 TTFT、selector ms、prefill 和 decode、KV 长度/position/mask 正确性。

## 后续是否允许加动态入口
只有当一种真实测量的低成本难度信号，能在数据分层上预测多保留入口 Token 的边际 ACC 收益、对照相同平均 W 和 budget permutation 胜出、且不引入不可接受延迟，才允许接入动态 Stage1。
如果固定日程换比值就足够强，或随机深层不弱于 RDRIFT，则简化模块；不为了故事堆叠新方法。

## 可证伪的决策标准
优先看同一问题集上的 GQA / POPE F1 / MME / MMB 原始指标及 bootstrap CI，并要求没有实质性的其他任务回退；效率指标必须进入 Pareto 前沿。新方案在简洁基线或同 W 强参照下没有稳定联合优势，就停止分支。
不要将 59+/85+ 写成成功保证；判断强弱仍要和当期可靠强基线同口径比较。
