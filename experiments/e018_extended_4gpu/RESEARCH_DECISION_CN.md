## 1. 当前证据到底支持什么

本轮完整阅读了当前上传的审核对话导出，以及可见的历史对话。附件是审核结论的文字记录，不是 E001–E017 原始日志、源码或逐样本预测。本轮没有重新运行项目 GPU，也没有恢复那些未提供的附件。

用户冻结的综合指标为：

R4 = 100/4 × (GQA/61.9 + POPE/85.8 + MME/1852 + MMBench/64.1)。

这里最后一项明确是 MMBench。当前只收到四个舍入后的 R4，没有每项任务原始值，不能独立重算这四个均值，也不能计算统计显著性。

| 因子 | ONE | TWO | TWO−ONE，百分点 |
|---|---:|---:|---:|
| COVER | 95.21 | 96.10 | +0.89 |
| BASE | 95.22 | 96.10 | +0.88 |
| COVER−BASE | −0.01 | 0.00 | 交互约 +0.01 |

四舍五入本身就足以影响最后这个 0.01 的符号和大小。可靠解释是：这组汇总值支持优先研究 TWO 对应的 Stage2 改变，没有显示 COVER 的额外主效应或与 TWO 的额外协同。它不否定 COVER 在其他工作点的价值，也不要求一篇统一方法的两个模块必须有正交互。

不能据此写“显著证明动态剪枝”，原因有四个：

1. 未知 ONE/TWO 的真正定义。若 TWO 是固定层位的两次删除，它属于渐进剪枝，并非逐样本自适应。若 TWO 是两次推理或按答案取优，解释还会完全不同。
2. 未知每层视觉数量和真实延迟，更多计算可能解释精度改善。
3. 没有配对预测与正确的任务重采样单位，无法给置信区间。
4. 未与同成本最强固定日程比较；优于一个旧日程不能证明自适应带来增量。

进入新实验前，Cursor 必须从配置和源码恢复这四臂的含义，不得根据 ONE/TWO 名字推断。

## 2. 对前面建议的取舍

停止把区域均值、代表点、动态交换量当作当前主攻方向。前面支持区域双参考的语气过早，现有新汇总值也没有提供继续扩展 Stage1 的理由。

Stage1 保留已有可信实现。在这个工作点上，先比较 BASE 与历史 COVER 的运行成本，冻结更简单且精度不劣的入口；不要默认必须使用 COVER，更不要新造一个覆盖公式。

审核建议的“淘汰内容摘要”值得检验，但不能因其叙述完整就认定有效：

- 幸存表示可能已包含足够上下文，额外历史完全可能冗余。
- Stage1 丢失的证据可能已经不可恢复；发现缺证据并不意味着延长剩余 token 计算有用。
- 复杂摘要读取可能比节省的计算还贵。

因此，把“淘汰历史提供独立的、可变现的预测信息”设为核心待检验机制。它失败则撤掉跨阶段历史主张。仅剩通用控制器时，也不能改名当作已建立的新贡献。

## 4. 唯一主推原型：压缩历史条件下的暂缓收益预测

研究对象从“信息有没有饱和”改成一个可干预的问题：

> 在实际发生的前置压缩之后，这次最终删除多等几层，是否真的能改善答案？淘汰内容是否能在幸存状态之外，帮助识别值得等待的样本？

先冻结 TWO 已有前置事件、最终 K、Q-ATTN 选点规则和后续 cache 语义。只在最后一次删除前设置二选一：

- early：当前完成 d 个 block 后立即减至 K。
- late：保持当前 Kprev，再经过 Δd 个 block 后按同一选择规则减至 K。

Δd 初始只取4作为待测超参数，必须受模型深度和实际工作点约束。数值不是从现有日志推导出来的最优值。半天不扩展到多个 K、多种评分和多个路由器。

这首先是一个最终删除时机的最小原型，不代表已经实现任意逐层动态删除。只有单决策有效，再考虑多检查点；多决策需要在真实策略访问状态上重新采样，不能复用不匹配的历史标签。

### 4.1 监督目标必须是可挽回的增量

从完全相同的 prompt-only 前缀 h_d 分两支，定义：

δ(h_d) = NLL_answer(early; h_d) − NLL_answer(late; h_d)。

两支参考答案 token、前缀、后续策略和随机状态一致；NLL 只对答案部分计算并按答案 token 数归一。δ 可以为负，代码不截断负值。

δ>0 才表示“等待在这对动作下有帮助”。两支都错且 NLL 都很差的样本，未必有大 δ。相对 dense 的总损伤不能替代这个标签，否则容易给不可恢复错误继续增加计算。

标签只在离线训练/开发源上产生。线上不读取答案、dense 输出、未来层或两个分支。方法允许训练一个小控制器，不能称为完全 training-free。

### 4.2 输入与历史的定义

公共输入：当前问题尾部 prompt token 的 hidden state、当前视觉状态的低维统计、已有 Q-ATTN 的统计、层位及预算信息。这个尾部位置是实用选择，不保证代表全部问题；必须与原项目 query span 对齐。

历史：Stage1 原本就计算过、但没有送入 LLM 的原始视觉 patch 内容。它在 encoder 特征空间独立投影并按显式空间/分块 ID 记录数量、均值和二阶矩。当前默认16组、8维投影，272维摘要。

摘要采用区域统计是控制存储/读取成本的工程原型，不是新的选点方法；二阶矩可暴露部分均值抵消，但也可能遗漏关键信息。它不证明覆盖完备，更不直接作为风险公式。若这类廉价摘要无效，先报告失败，不在这轮继续增加摘要网络。

不同模态独立投影后由训练的控制器融合，绝不直接把 CLIP token 当 decoder K，也不直接比较独立投影空间的余弦。投影矩阵必须持久化并在训练/部署间保持相同。

采用一层32宽 tanh 隐层回归器。公共输入默认55维，加272维摘要，约1万参数。小模型结构是验证载体，不是创新点。

### 4.3 唯一决定规则

暂缓当且仅当：δ_hat(h_d, history) > λ × ΔT_hat。

ΔT_hat 来自冻结的真实成本表，单位毫秒；λ 单位为 NLL/毫秒，只在开发集校准。实际占用预算及控制器开销仍需线上重测。不能把 token-layer 当精确延迟，也不能用测试结果重新选 λ。

成本表随当前 Kprev、目标 K、暂缓层数、文本长度、backend/cache 语义变化；不能拿一条全局常数套所有上下文。测得额外成本不为正时先调查噪声与实现，不自动截为零。

### 4.4 为什么它有可能比拼接故事更完整

如果成立，逻辑是：前置压缩改变后续计算的可挽回收益；被删内容提供幸存状态之外的预测信息；用这种预测把有限的额外计算给真正受益的样本。

这串逻辑只有一个中心变量——额外计算带来的真实边际收益。Stage1 无须再制造一个新模块，后续也无须同时发明新选点分数。

但普通两动作控制器与已有路由/序贯方法仍然接近。真正需要建立的区别只有：跨阶段淘汰内容提供独立、成本可接受、可迁移的作用。如果这个机制失败，当前原型不足以支撑原定贡献。不可用“信息债”“证据寿命”等换名来补救。

## 5. 必须同时具备的四类对照

**信息增量**：所有控制器输入维度、隐层宽度、训练步骤、种子、训练数据一致，分别使用 zero、geometry、retained、history。retained 控制的摘要数量/位置字段替换为与 history 完全相同，只保留内容统计的差别；不能让 history 仅凭缺失位置元数据取胜。geometry 分离位置/缺口与语义内容的作用。

真正的主比较是“重新训练的 retained 控制”对“重新训练的 history 控制”。只在测试时打乱历史会引入分布外输入，不能替代这个比较。若 history 只优于 zero，不能证明淘汰语义有独立作用。

**动态价值**：强固定 ONE/TWO、最后删除层位附近的固定日程包络、同动作占比随机/打乱分配、简单 attention entropy 预算控制，以及上述 retained 控制器。固定日程范围先用开发集确定，独立测试时不能再挑最好的层。

**预算一致**：每样本记录所有 block 的视觉数量，报告 token-layer、估算完整 FLOPs 和真实 TTFT/固定生成长度时间。比较精度时应给成本包络；同平均 token-layer 也不等于同延迟。

例如32层、入口172、完成4层减至96，完成8/12层减至32，两条路线分别为1840/2096 token-layer，相差256。它们只是代码单元测试的示例，不是对 ONE/TWO 的还原。平均分配一半到 late 的1968也只是工作量代理，不能写成固定64或平均32预算。

**任务完整性**：NLL 是训练代理，最终结论要由官方任务正确率及端到端性能裁定。POPE 明确 accuracy/F1 的 metric key；MME 按官方配对/类别规则重算；MMBench 记录split与打分版本。不能把所有任务当简单逐题 accuracy 后直接 bootstrap。

独立 OCR/计数/细粒度样本与真正同图多问样本用于检查预算变化是否随问题改变。最终还需现代架构、不同入口与预算、完整生成稳定性和直接近邻基线。四任务 R4 仅作项目内冻结指标，不是投稿充分条件。

## 6. 半天后的成功与停止标准

半天的合理目标是完成一条可复核的机制证据链，不能承诺做出全部投稿结果。

先观察真实 early/late 对的正确性互补和固定成本下的 oracle 上界。若多数样本没有可挽回收益，或 oracle 也不能比强固定包络更好，就不投入控制器扩展。

若 oracle 有余量，但 learned controller 没有效果，区分样本量不足、标签代理不对、状态特征不足与机制本身冗余；这不证明机制在数学上不可能，但在当前时间预算下不应继续升格为主线。

只有 history 在独立图像组上稳定优于 retained/geometry，且在同成本在线正确率上兑现、测量开销后仍有优势，才继续主方法。

若 history 无增量但普通暂缓控制有收益，可以保留为强工程结果/对照；不能据此宣称跨阶段历史创新。若动态控制没有赢固定包络，保留强固定渐进版本，停止增加动态故事。

要达到有竞争力的 CVPR 方法证据，还须补：现代模型迁移、视觉密集任务、直接近邻、多个预算的精度—实测延迟曲线、容量/信息/成本控制、训练数据隔离与机制失败案例。没有任何一轮半天实验或公式设计能预先保证录用。
