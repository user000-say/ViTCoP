必要的辅助说明包括：writer 的 `references/exemplar-style-analysis.md`、`section-modules.md`，optimizer 的 `references/problem-method-blueprint.md`，common 的 `references/privacy-and-evidence.md` 与 `artifact-contracts.md`。按相关任务读取，保留原目录的相对依赖关系，不只复制一份 SKILL.md。

本任务采用以下具体原则：

- 先读真实连贯原文，卡片提供定位；学习句间/段间的论证关系，保留科学归属。
- 研究主张由来源和实际算法约束；没有把模块命名当作机制。
- 直接修改 canonical LaTeX 文件；切换技能不复制另一套论文。
- Reviewer 判断、writer 修改；同一个 Agent 的角色切换不算独立审稿。
- 缺失事实只约束依赖它的主张，继续完成其他部分；不编造实验填空。
- 模板指南可能随版本变化；用户提供的模板与当前官方投稿规则共同核对，不盲用仓库旧 venue guide。
- 当前范围为写作；研究分支探索、模型实验和外部发布均不自动启动。

本交接没有修改或安装用户的技能，也没有更改个人默认配置。Cursor 若有现成安装，可直接使用；未安装时按仓库的 [Cursor 说明](https://github.com/mikubaka88/CCFA-Skills/blob/main/docs/getting-started/CURSOR.md) 或 [安装矩阵](https://github.com/mikubaka88/CCFA-Skills/blob/main/docs/INSTALLATION_MATRIX.zh-CN.md)处理。这里不把规程阅读报告成客户端安装。

后续写作首次复核 15 篇相关原文后，局部修改复用适用的原文与分析；不为每个句子重复执行整套检索和审稿流程。
