# 如何把这个包交给 Cursor

1. 解压整个包，在 Cursor 中打开该目录；如需读取生产代码，把 BELA 代码仓库同时加入工作区，或明确告诉 Agent 真实路径。不要用底稿覆盖已有更新稿，先比较版本。
2. 将下面的启动消息发送给 Agent。它的正式任务入口是 `CURSOR_HANDOFF_ZH.md`。
3. Agent 会先读材料、原文和真实代码，再直接修改 `paper/`，完成中文非实验稿与 PDF。

```text
请读取 CURSOR_HANDOFF_ZH.md，并按其全部要求执行。
先使用 CCFA-Skills 核对 15 篇论文的相关原文，读取本包实验记录，
追踪我当前 BELA 仓库的真实调用链，再确定论文中心主张并直接改 paper/。
本轮写中文摘要、引言、相关工作、方法和结论，实验章节暂不启用。
严格沿用所附 CVPR 模板，完成科学评审与事实引用核查，实际编译并检查 PDF。
持续完成工作，不停在规划；无法查明的具体事项集中记入作者核对文件。
```

包内的 `paper/main.pdf` 是 v03 编译底稿，`paper/` 为对应可编辑源文件。新的正文完成后要重新编译。完整生产代码和原始逐样本预测未包含在本包，需从你的实际项目读取。

文献卡片为本次写作分析，不是其他论文全文副本；公开原文下载地址与所读版本记录在 `papers/`。目录中的 `research/` 和 `inputs/` 服务于作者写作，不能作为匿名投稿的公开外链或补充证据替代实际实验。

本包未运行模型评测，也未替作者修改生产算法。
