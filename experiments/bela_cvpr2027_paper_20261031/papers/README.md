## 阅读验收

记录论文实际科学对象、操作、条件与证据，再分析句段如何推进。写作建议单独标示；不要以标题或摘要推断全文结构。对公式、图和双栏提取有疑问时渲染核对原页。原文获取失败时尝试作者/会议的其他原始来源，记录实际覆盖范围，不把缺失项写成已读。
