# CVPR 2027 eligibility / integrity checklist
Official: https://cvpr.thecvf.com/Conferences/2027/AuthorGuidelines
Deadline: Enrollment Nov10 AoE, Full Nov16 AoE, Supplementary Nov23 AoE. Fixed.
- [ ] Use official CVPR 2027 anonymous template; max 8 main pages excluding references and the required LLM usage statement.
- [ ] All author OpenReview profiles and enrollment forms complete by Nov10; authors CANNOT be added/removed after.
- [ ] Check 2027 reciprocal-reviewer quota against full author team (max one paper per author without eligible reciprocal reviewer).
- [ ] Mandatory LLM Usage Statement accurately acknowledges LLM assistance; omission risks desk reject.
- [ ] No unapproved author-identifying repository links/screenshots in manuscript or supplements.
- [ ] No unreproducible numbers, invented SOTA or ungrounded latency claims; maintain code hash and dataset/evaluator manifests.
- [ ] Related contemporaneous work after Sep15 still discussed, and any work that influenced us must be cited.
- [ ] Title + abstract + authors ready for Nov10; final main text in official format before Nov16.
- [ ] Double-blind, citation and original figure rules observed.
