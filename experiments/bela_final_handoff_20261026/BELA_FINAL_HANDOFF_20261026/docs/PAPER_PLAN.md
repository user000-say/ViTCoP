# 论文与实验收敛

## 1. 先形成证据链，再冻结Method

目前可用作背景的事实是入口guide与阶段分配影响任务表现；尚未证明新的跨阶段纠错机制。不要把相同事实先命名成“任务特质分工”，再挑案例为它背书。

最值得争取的、仍待验证的问题陈述：入口候选的即时评分改善，不保证答案收益经后续容量约束的筛选完整保留。论文需要定位其发生条件，并证明删除前可获得的信息能指导有效、低成本的纠错。

暂定工作标题可用“Where Admission Gains Disappear in Multi-Stage Visual Token Pruning”。它是问题导向的占位标题，不代表已得到该发现。方法失败后必须改标题与Abstract，不强行保留。

GQA可按属性/关系/计数/存在题型分组；标签来自实际数据定义，不自行猜。POPE必须分random/popular/adversarial及FP/FN，解释对象缺失与语言倾向的区别。TextVQA用官方软分；MME保留perception/cognition/total与原复合计分。

随机选择难度与Dense-correct preservation可作为补充，引用PAA-Bench，不列为我们提出的评估。Dense错误→正确与正确→错误同时报告，避免只统计损伤或只统计收益。

## 3. 创新结论要逐层获得

层1：本项目观察可重复，且与已发表定性图不同的具体条件清楚。层2：受控干预能排除同容量随机扰动或实现差异。层3：在线信号有效，弱先验如何影响合法选择可解释。层4：在95/98研发目标、原始核心指标及真实成本上有竞争力。每层都不自动推出下一层。

即使实验机制成立，仍须正面讨论E2S冲突保护、CoRe条件删除、CoViST状态继承与QC/CoverPruner覆盖目标的重叠。更高ACC可以支持实用性，但不能替代贡献区别。

## 4. 冻结规则

A/S/AS先导后选择至多一个主要候选配置/预算，冻结lambda、名额和所有解析规则。只有明显实现错误或新否定证据才改；每次修改写原因与影响范围。完整测试集不再循环挑超参。

若AS胜出，完整两因子消融对Native/A/S/AS使用同预算与协议；随机和去门控对照匹配胜者。如果A或S单独胜出，不要求两处都新。若负控等效，则收缩信号主张。若95/98未达到，报告真实结果与差距，不把“接近目标”改写成达标。
