# 与恢复版 R2 的联系和变化

本包是基于本对话工作区内恢复版 R2 的两档修订。服务器用户报告的 commit 486fc68 没有完整 checkout 或源文件可读，不能把这里的文件对比冒称该提交的逐行 git diff。

| 内容 | R2 恢复版 | 本包 R3 |
|---|---|---|
| 已有数值模块 | 原 IDs / raw pen / dual beta / 精确预算 / Torch kernels | 11 个 elva 原模块逐字保留，SHA 校验见 validation |
| 主预算 | 旧目录含中间档和大量储备 | 活跃配置仅 W2048 / W1024 |
| 88.9% 入口 | 原计划未固定本日程 | 172×4 + 90×8 + 32×20 = 2048 |
| 94.4% 入口 | 60/28/12 计划 | 60×10 + 28×10 + 12×12 = 1024 |
| COVER 缺失 | 服务器报告 V4/V5 未实际调用 | 无绑定即 BLOCKED，不以TopK冒充 |
| K60 覆盖 | 原 K172/b32 的兼容问题未解 | 新 PCOV60/b12 独立实装；原 PORT60/b11 可选；池化截断仅诊断 |
| 真实 Stage1 forward | 选点算子/通用capture | 新增 CLIPStage1/encode_projected：原单次ViT、单CLS评分、raw pen取行、原投影 |
| 收敛控制 | 多配置目录 | 10核心；扩展按条件与精确ID；冻结后才启Stage2 |
| 逐例验收 | 局部/结构检查 | 完整32层trace、实际生成、IDs、coverage来源/调用/容量、scorer与源码指纹 |
| 图示 | 独立图示工具 | 合并热点/共有独有图；新增K60覆盖–显著性–最终新增点图 |
| GPU 调度 | 粘贴空闲状态/物理编号 | 当前UUID、进程/显存、分片全局限额、可见设备、同用户租约 |

PCOV 使用普通覆盖优化和显著性保护，作为透明控制，不声称论文新算法已经成立。原 COVER 继续由当前服务器真实源码绑定；新的 PCOV 不能计为原 COVER 复现。所有学习/交换训练在活跃配置中关闭。

本包已实际写入选点算法、前向桥接、配置/运行/验收和绘图代码。仍需 Cursor 在服务器准确接入原模型序列组装、原 Q_ATTN/decoder compaction、原 COVER 和官方任务循环。私有源文件没有提供，不存在已应用到服务器的逐行补丁，也没有新的真实 ACC/TTFT 结果。

验证结果以 validation/summary.json 和完整日志为准。PyTorch相关项在当前本地缺少Torch时明确跳过，必须在现有服务器环境执行。fixture仅证明实现/绘图通路，不证明VLM效果。
